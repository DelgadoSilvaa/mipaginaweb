¿Qué es GitHub?

La plataforma de desarrollo colaborativo más grande del mundo

Concepto Principal

GitHub es una plataforma basada en la nube que permite a los desarrolladores almacenar, gestionar y compartir su código fuente. Utiliza el sistema de control de versiones Git para rastrear todos los cambios realizados en un proyecto.

Diferencia entre Git y GitHub

  • Git: Es la herramienta de líneas de comandos instalada en tu computadora local que rastrea el historial de cambios de tus archivos.
  • GitHub: Es el servicio web en la nube donde subes la copia de tu repositorio de Git para trabajar en equipo, respaldar tu código o compartirlo públicamente.

Funciones Clave

  • Repositorios (Repositories): Carpetas donde se almacena el código de un proyecto junto con su historial.
  • Commits: Puntos de guardado que registran modificaciones específicas en los archivos.
  • Ramas (Branches): Espacios de trabajo independientes para probar nuevas funciones sin alterar el código principal (main).
  • Pull Requests (PR): Propuestas para integrar cambios de una rama hacia otra, permitiendo la revisión de código entre compañeros.

Página creada para aprender los conceptos básicos de Git y GitHub.

""" with open("index.html", "w", encoding="utf-8") as f: f.write(html_content) print("Archivo index.html generado correctamente")
